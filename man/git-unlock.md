git-unlock(1) -- Unlock a file excluded from version control
============================================================

## SYNOPSIS

`git unlock` [-h|--help] &lt;filename&gt;...

## DESCRIPTION

  Unlock local files from version control.

## OPTIONS

  -h, --help

  Show help message.

  &lt;filename&gt;...

  The name of the file(s) to unlock.

## EXAMPLES

    $ git unlock config/database.yml
