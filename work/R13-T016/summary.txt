Branch Simplification & Readability Explanation:
  In bin/git-sync, the confirmation/execution branch in main() was simplified. Previously, the execution branch duplicated 'git fetch "${remote}" "${branch}" && git reset --hard "${remote_branch}"' across both the soft=true and soft=false branches. The implementation now executes the core fetch-and-reset operation as a single unified step, followed by untracked cleanup ('git clean -d -f -x') executed conditionally only when soft!=true. This clearly separates the synchronization responsibility from the working tree hygiene responsibility while strictly preserving all observable behavior.
